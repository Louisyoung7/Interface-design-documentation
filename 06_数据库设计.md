# 06 · 数据库设计（PostgreSQL + pgvector）

> 版本 V1.4　|　统一存储：结构化关系数据与说明书向量数据同库存放（PostgreSQL 启用 pgvector 扩展），不单独部署向量数据库。
> 命名：表名小写下划线、主键统一 `id BIGSERIAL` 或业务主键、时间统一 `TIMESTAMPTZ`（UTC）。外键关系在注释中标注，是否建物理外键由团队决定。

## 1. 实体关系总览

```
User(老人/监护人) --1:N-- GuardianRelation --N:1-- User(老人)
Elder(=User.role=ELDER) --1:N-- Device
Device --1:N-- Compartment --N:1-- Medicine
Elder  --1:N-- MedPlan --N:1-- Medicine
MedPlan--1:N-- MedRecord
Device --1:N-- EnvSample
Elder  --1:N-- Alarm ; Elder --1:1-- AlarmSetting ; Elder --1:1-- LlmConfig
Medicine--1:N-- DrugManual --1:N-- DrugManualChunk(pgvector)
```

## 2. 关系表设计

### 2.1 user 用户（老人 + 监护人，含角色）

```sql
CREATE TABLE "user" (
    id             BIGSERIAL PRIMARY KEY,
    user_id        VARCHAR(64)  NOT NULL UNIQUE,        -- 业务ID
    username       VARCHAR(64)  UNIQUE,                 -- 登录账号（可空，手机号亦可直接登录）
    password_hash  VARCHAR(100) NOT NULL,               -- BCrypt 加盐哈希，永不存明文
    name           VARCHAR(64),
    phone          VARCHAR(20)  UNIQUE,                 -- 登录账号（与 username 二选一）
    role           VARCHAR(16)  NOT NULL,               -- ELDER 老人 / GUARDIAN 监护人
    wechat_open_id VARCHAR(64) UNIQUE,                  -- 【暂不使用】预留，接入微信登录时启用
    created_at     TIMESTAMPTZ DEFAULT NOW()
);
```

### 2.2 guardian_relation 老人↔监护人绑定

```sql
CREATE TABLE guardian_relation (
    id          BIGSERIAL PRIMARY KEY,
    elder_id    VARCHAR(64) NOT NULL,   -- -> user.user_id (ELDER)
    guardian_id VARCHAR(64) NOT NULL,   -- -> user.user_id (GUARDIAN)
    role        VARCHAR(16),            -- FAMILY 家属 / DOCTOR 医生 / NURSE 护理
    status      VARCHAR(16) NOT NULL,   -- PENDING 待授权 / ACTIVE / REVOKED
    created_at  TIMESTAMPTZ DEFAULT NOW(),
    UNIQUE (elder_id, guardian_id)
);
```

### 2.3 device 设备

```sql
CREATE TABLE device (
    id              BIGSERIAL PRIMARY KEY,
    device_id       VARCHAR(64) NOT NULL UNIQUE,
    product_key     VARCHAR(64),
    secret          VARCHAR(128),                -- MQTT 一机一密 / 用户名密码凭据（加密存储）
    elder_id        VARCHAR(64),                 -- -> user.user_id (ELDER)
    online_state    VARCHAR(16) DEFAULT 'OFFLINE',-- ONLINE / OFFLINE（MQTT 遗嘱+心跳维护）
    firmware_ver    VARCHAR(32),
    last_heartbeat  TIMESTAMPTZ,
    created_at      TIMESTAMPTZ DEFAULT NOW()
);
```

### 2.4 medicine 药品档案

```sql
CREATE TABLE medicine (
    id               BIGSERIAL PRIMARY KEY,
    medicine_id      VARCHAR(64) NOT NULL UNIQUE,
    name             VARCHAR(128) NOT NULL,
    spec             VARCHAR(64),                 -- 规格
    dose_per_time    VARCHAR(32),                 -- 单次剂量
    unit             VARCHAR(16),                 -- 片/粒/ml...
    contraindication TEXT,                        -- 禁忌
    storage_cond     VARCHAR(128),                -- 储存条件（温湿光阈值描述）
    created_at       TIMESTAMPTZ DEFAULT NOW()
);
```

### 2.5 compartment 仓位（分格库存 + 有效期 + RFID）

```sql
CREATE TABLE compartment (
    id          BIGSERIAL PRIMARY KEY,
    device_id   VARCHAR(64) NOT NULL,   -- -> device.device_id
    slot_no     INT         NOT NULL,   -- 仓位编号
    medicine_id VARCHAR(64),            -- -> medicine.medicine_id（可空=未绑定）
    quantity    INT         DEFAULT 0,  -- 库存数量
    expiry_date DATE,                   -- 有效期
    rfid_tag    VARCHAR(64),            -- 仓位 RFID 标签
    UNIQUE (device_id, slot_no)
);
```

### 2.6 med_plan 服药计划

```sql
CREATE TABLE med_plan (
    id                  BIGSERIAL PRIMARY KEY,
    plan_id             VARCHAR(64) NOT NULL UNIQUE,
    elder_id            VARCHAR(64) NOT NULL,   -- -> user.user_id (ELDER)
    medicine_id         VARCHAR(64) NOT NULL,   -- -> medicine.medicine_id
    slot_no             INT,                     -- 对应仓位
    times               JSONB NOT NULL,          -- ["08:00","20:00"]
    dose                VARCHAR(32),
    unit                VARCHAR(16),
    repeat_rule         VARCHAR(16),             -- DAILY / WEEKLY ...
    miss_alarm_after_min INT DEFAULT 15,         -- 漏服容忍(分钟)
    alarm_rule          JSONB,                    -- {miss,wrongDrug,expired,env}
    status              VARCHAR(16) DEFAULT 'ENABLED',
    created_at          TIMESTAMPTZ DEFAULT NOW()
);
```

### 2.7 med_record 服药记录（设备上报生成）

```sql
CREATE TABLE med_record (
    id           BIGSERIAL PRIMARY KEY,
    record_id    VARCHAR(64) NOT NULL UNIQUE,
    plan_id      VARCHAR(64),          -- -> med_plan.plan_id
    slot_no      INT,
    actual_dose  VARCHAR(32),
    plan_time    TIMESTAMPTZ,
    actual_time  TIMESTAMPTZ,
    on_time      BOOLEAN,               -- 是否按时
    wrong_drug   BOOLEAN,               -- 是否错服
    device_id    VARCHAR(64),           -- -> device.device_id
    created_at   TIMESTAMPTZ DEFAULT NOW()

```

### 2.8 env_sample 环境遥测（MQTT 上报入库）

```sql
CREATE TABLE env_sample (
    id          BIGSERIAL PRIMARY KEY,
    device_id   VARCHAR(64) NOT NULL,   -- -> device.device_id
    temperature NUMERIC(5,2),
    humidity    NUMERIC(5,2),
    lux         NUMERIC(8,2),
    sample_time TIMESTAMPTZ NOT NULL
);
CREATE INDEX idx_env_sample_device_time ON env_sample (device_id, sample_time);
```

### 2.9 alarm 告警

```sql
CREATE TABLE alarm (
    id           BIGSERIAL PRIMARY KEY,
    alarm_id     VARCHAR(64) NOT NULL UNIQUE,
    elder_id     VARCHAR(64),           -- -> user.user_id (ELDER)
    device_id    VARCHAR(64),           -- -> device.device_id
    type         VARCHAR(24) NOT NULL,  -- MISS / WRONG_DRUG / EXPIRED / ENV / DEVICE_OFFLINE
    level        VARCHAR(16),           -- INFO / WARN / CRITICAL
    message      TEXT,
    read_state   BOOLEAN DEFAULT FALSE,
    handle_state VARCHAR(16) DEFAULT 'OPEN',  -- OPEN / HANDLED
    created_at   TIMESTAMPTZ DEFAULT NOW()
);
CREATE INDEX idx_alarm_elder_read ON alarm (elder_id, read_state, created_at);
```

### 2.10 alarm_setting 告警规则与阈值（每老人一份）

```sql
CREATE TABLE alarm_setting (

    elder_id            VARCHAR(64) NOT NULL UNIQUE,  -- -> user.user_id (ELDER)

    miss_tolerate_min   INT,               -- 漏服容忍时长
```

## 3. 说明书知识库（pgvector 向量表）

启用扩展：

```sql
CREATE EXTENSION IF NOT EXISTS vector;
```

### 3.1 drug_manual 说明书（监护人上传的原始图片 / PDF）

```sql
CREATE TABLE drug_manual (
    id           BIGSERIAL PRIMARY KEY,
    manual_id    VARCHAR(64) NOT NULL UNIQUE,
    medicine_id  VARCHAR(64) NOT NULL,   -- -> medicine.medicine_id
    elder_id     VARCHAR(64),            -- 关联老人（可空，公共药品可空）
    source_type  VARCHAR(32) NOT NULL,   -- IMAGE / PDF
    file_url     VARCHAR(512) NOT NULL,  -- 原始文件存储路径
    page         INT,
    status       VARCHAR(16) NOT NULL DEFAULT 'PARSING',  -- PARSING / INDEXED / FAILED
    created_at   TIMESTAMPTZ DEFAULT NOW()
);
```

### 3.2 drug_manual_chunk 说明书分块（RAG 召回单元）

```sql
CREATE TABLE drug_manual_chunk (
    chunk_id     BIGSERIAL PRIMARY KEY,
    manual_id    BIGINT NOT NULL,        -- -> drug_manual.id
    medicine_id  BIGINT NOT NULL,        -- -> medicine.id（召回过滤维度）
    elder_id     BIGINT,                 -- 召回过滤维度
    page         INT,
    chunk_index  INT,                    -- 块序号，便于答案标注出处
    content      TEXT NOT NULL,          -- 切块后正文（OCR 转写结果）
    source_type  VARCHAR(32) NOT NULL,   -- OCR / MANUAL / PDF
    embedding    vector(1024),           -- 本地 bge-m3 = 1024 维；换模型必须重建向量
    created_at   TIMESTAMPTZ DEFAULT NOW()
);
-- 向量近邻索引（HNSW + 余弦）
CREATE INDEX ON drug_manual_chunk USING hnsw (embedding vector_cosine_ops);
```

### 3.3 召回检索（带过滤，避免跨药品 / 跨老人召回）

```sql
SELECT chunk_id, medicine_id, content,
       embedding <=> :qvec AS distance
FROM drug_manual_chunk
WHERE medicine_id = :mid
ORDER BY distance
LIMIT 5;
```

约束：`embedding` 维度必须与所选 embedding 模型一致 —— **本地 `bge-m3` 为 1024 维**（若改用其他模型，须同步改维度并**重建全部分块向量**，否则检索结果无意义）；`<=>` 为余弦距离算子；召回尽量带 `medicine_id` / `elder_id` 过滤；分块保留页码 / 块序号 / 来源，便于答案标出处。Spring AI `PgVectorStore` 亦可自动建表（`dimensions=1024`、`distance-type=COSINE_DISTANCE`、`index-type=HNSW`），字段名按框架默认即可，与上表等价。
